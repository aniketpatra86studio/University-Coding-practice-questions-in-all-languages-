# Product Inventory Low Stock Alert

## Problem Statement
You are developing an inventory alert system for a warehouse. The system stores product names and their stock quantities in two arrays:

* A String array containing product names.
* An integer array containing the stock quantity for each product.

The stock quantity at each index corresponds to the product at the same index.
The user enters a stock threshold. Your program must display all products whose stock quantity is less than or equal to the threshold (i.e., products that need restocking), along with their name and quantity.

## Input Format
```
Line 1:         N              (integer — number of products)
Line 2 to N+1:  <ProductName> <Quantity>   (one product per line, space-separated)
Line N+2:       T              (integer — stock threshold)
```

## Constraints
* 1 ≤ N ≤ 100
* 0 ≤ Quantity ≤ 10000
* 0 ≤ T ≤ 10000
* Product names contain no spaces.

## Output Format
* Display all products whose quantity is <= T, one per line, in the format:
```
ProductName - Quantity
```
* If no product needs restocking, display:
```
Stock levels are healthy
```

## Sample Input
```
4
Notebook 12
Pen 200
Stapler 5
Eraser 40
20
```

## Sample Output
```
Notebook - 12
Stapler - 5
```

## Solution (Java)
```java
import java.util.*;

public class Solution {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = Integer.parseInt(sc.nextLine().trim());

        String[] names = new String[n];
        int[] qty = new int[n];

        for (int i = 0; i < n; i++) {
            String[] parts = sc.nextLine().trim().split("\\s+");
            names[i] = parts[0];
            qty[i] = Integer.parseInt(parts[1]);
        }

        int t = Integer.parseInt(sc.nextLine().trim());

        boolean found = false;
        for (int i = 0; i < n; i++) {
            if (qty[i] <= t) {
                System.out.println(names[i] + " - " + qty[i]);
                found = true;
            }
        }

        if (!found) {
            System.out.println("Stock levels are healthy");
        }
    }
}
```
