# Restaurant Menu Price Filter

## Problem Statement
You are building a menu search feature for a restaurant app. The system stores dish names and their prices in two arrays:

* A String array containing dish names.
* A double array containing the price of each dish.

The price at each index corresponds to the dish at the same index.
The user enters a maximum budget. Your program must display all dishes whose price is less than or equal to the budget, along with their name and price.

## Input Format
```
Line 1:         N              (integer — number of dishes)
Line 2 to N+1:  <DishName> <Price>   (one dish per line, space-separated)
Line N+2:       B              (double — maximum budget)
```

## Constraints
* 1 ≤ N ≤ 100
* 0.0 ≤ Price ≤ 5000.0
* 0.0 ≤ B ≤ 5000.0
* Dish names contain no spaces.

## Output Format
* Display all dishes whose price is <= B, one per line, in the format:
```
DishName - Price
```
* If no dish fits the budget, display:
```
No dishes within budget
```

## Sample Input
```
5
Pizza 350.0
Burger 150.0
Pasta 280.0
Sushi 600.0
Salad 120.0
300.0
```

## Sample Output
```
Burger - 150.0
Pasta - 280.0
Salad - 120.0
```

## Solution (Java)
```java
import java.util.*;

public class Solution {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = Integer.parseInt(sc.nextLine().trim());

        String[] names = new String[n];
        double[] prices = new double[n];

        for (int i = 0; i < n; i++) {
            String[] parts = sc.nextLine().trim().split("\\s+");
            names[i] = parts[0];
            prices[i] = Double.parseDouble(parts[1]);
        }

        double b = Double.parseDouble(sc.nextLine().trim());

        boolean found = false;
        for (int i = 0; i < n; i++) {
            if (prices[i] <= b) {
                System.out.println(names[i] + " - " + prices[i]);
                found = true;
            }
        }

        if (!found) {
            System.out.println("No dishes within budget");
        }
    }
}
```
