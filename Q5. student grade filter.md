# Student Grade Filter

## Problem Statement
You are building a simple system to filter students who passed an exam. The system stores student names and their marks in two arrays:

* A String array containing student names.
* An integer array containing their marks (out of 100).

The marks at each index correspond to the student at the same index.
The user enters a minimum passing mark. Your program must display all students whose marks are greater than or equal to the passing mark, along with their name and marks.

## Input Format
```
Line 1:         N              (integer — number of students)
Line 2 to N+1:  <StudentName> <Marks>   (one student per line, space-separated)
Line N+2:       P              (integer — passing marks)
```

## Constraints
* 1 ≤ N ≤ 100
* 0 ≤ Marks ≤ 100
* 0 ≤ P ≤ 100
* Student names contain no spaces.

## Output Format
* Display all students whose marks are >= P, one per line, in the format:
```
StudentName - Marks
```
* If no student satisfies the passing marks, display:
```
No students passed
```

## Sample Input
```
5
Ravi 78
Meena 55
Arjun 91
Divya 40
Kabir 65
60
```

## Sample Output
```
Ravi - 78
Arjun - 91
Kabir - 65
```

## Solution (Java)
```java
import java.util.*;

public class Solution {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = Integer.parseInt(sc.nextLine().trim());

        String[] names = new String[n];
        int[] marks = new int[n];

        for (int i = 0; i < n; i++) {
            String[] parts = sc.nextLine().trim().split("\\s+");
            names[i] = parts[0];
            marks[i] = Integer.parseInt(parts[1]);
        }

        int p = Integer.parseInt(sc.nextLine().trim());

        boolean found = false;
        for (int i = 0; i < n; i++) {
            if (marks[i] >= p) {
                System.out.println(names[i] + " - " + marks[i]);
                found = true;
            }
        }

        if (!found) {
            System.out.println("No students passed");
        }
    }
}
```
